# 이전 포트폴리오

- `v0/`: 기존 HTML·jQuery 포트폴리오. 원래 파일의 폴더 내 상대 경로를 유지합니다.
- `v1/`: v2 전환 직전 Next.js 원본. 2026-10-23 백업 커밋 `5ba289c114ed8fe9a1605cec7d0e8c646f3ddebd`의 소스이며 당시 미커밋 변경도 포함합니다.

현재 포트폴리오는 저장소 루트에서 실행합니다. 이전 버전은 현재 앱의 빌드·lint·타입 검사 대상에서 제외합니다. v1에는 재생성 가능한 node_modules·빌드 결과와 v0의 중복 사본은 넣지 않았습니다.

원본을 실행하려면 `v1/`을 별도 폴더로 복사한 뒤 `npm ci`, `npm run build`, `npm run start`를 실행합니다. Git 브랜치로 정확히 복원하는 방법은 루트의 `docs/rollback.md`를 참고하세요.
